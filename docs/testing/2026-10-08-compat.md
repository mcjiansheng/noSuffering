## 隔离及真实操作

## 主环境与 Mod 共存

xht-rog 主 beta 环境已部署相同 0.1.1 DLL，其他 Mod 保持原状。在既有已登录 Steam 桌面会话执行真实 headless 主菜单启动：Steam 初始化成功，NoSuffering 0.1.1 初始化成功，加载 25 个 Mod，退出码 0。临时计划任务 NoSuffering-StartupCheck 已删除。[脱敏证据](compat-evidence/windows-beta-mods.txt)。

组合包括 BaseLib 3.4.7、RitsuLib 0.6.7、UndoAndRestart 0.111.0.4、intentgraph2 1.6.0、CustomCardBalance 2.9.1、AncientSL 1.0 及外观 Mod。MintySpire2 安装但禁用。只认定启动共存，不认定全组合玩法、历史清理、先古互操作或联机兼容。可选单步撤销适配未交付，不阻塞核心。

## 修复与未完成范围

正式版首次构建因原生大厅、网络构造器和 RNG API 差异失败；按实际程序集修复后四目标分别构建通过。副环境首次启动因原生 Mod 提示未同意而不加载，保留失败记录；随后仅启用专用副环境设置，再验证初始化。原生 ModManager 会递归把文档 JSON 识别为 Mod manifest，安装包已将证据 JSON 改为 `.txt`，构建记录也使用 `.txt`；源项目的原始记录格式不变。修复后 Windows 正式版再次启动通过。

旧探针的一次独立进程检查因“菜单不能已经读过伴随存档”的假设而失败；真实原生菜单会预读存档，改用不同进程 PID、实际磁盘配对和战斗抽牌验证后通过。Mac headless 纹理初始化及退出资源 / RID 警告、主环境其他 Mod 的旧依赖格式警告仍有记录，没有宣称整段日志无错误。

DESIGN 的 T05、T06、T10、T11 获得单人原生路径的部分证据；不能将探针覆盖直接写作这些完整验收项通过。T01–T22 均未完成全量验收。以下范围明确未执行：付费刷新和生命不足、领取竞态、实际跨幕回滚、战斗中回滚、固有 / 特殊起手、开场效果完整资源核对、F6/Fn 与 UI 缩放、ModConfig 设置页和配置重启、其他角色、Intel Mac、Mod 玩法组合互操作。

双人、满员、客户端权限、断线重连与真实 Steam 联机按用户“测试在后续考虑”的安排未执行。独立离线进程 Continue 不等于联机重连。不会宣称支持未来版本或所有常用 Mod。
