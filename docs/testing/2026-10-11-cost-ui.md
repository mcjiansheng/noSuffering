## Mac beta 实际界面

通过 Computer Use 操作真实游戏进程的自带设置（中文，独立副测试环境，仅 NoSuffering）：

- 两项均为免费：不出现金额输入，两行各自标明功能。
- 第一项切换扣血：显示“5 生命”，第二项仍免费且不显示金额。
- 第一项金额改为 7，切回免费再切回扣血：重新显示“7 生命”。
- 第二项切换扣血：显示“5 生命”，第一项仍是 7，两行布局没有重叠。
- 退出后配置保留 AncientHpCost=7、OptionsHpCost=5，两个模式均为 Hp。

本地证据目录：`artifacts/0.1.7/ui-20261011-130258/`，含引擎日志、前后配置与恢复记录；截图来自本次 CUA 输出。验证后退出测试进程，恢复副环境原配置及模组，`profile_restored=true`。未使用主存档。
