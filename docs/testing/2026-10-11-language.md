# 0.1.6 跟随游戏语言

日期：2026-10-11（Asia/Shanghai）。需求依据：DESIGN v1.10 / T39。机器可读结果见 [validation.json](evidence/0.1.6/validation.json)。

## 变更

语言直接来自游戏 LocManager，自带设置、BaseLib 和 ModConfig 均移除独立语言项。游戏中英文切换后，已打开的自带设置和 BaseLib 页面立即更新。中文游戏语言使用现有简体中文，其余使用英文译文；本轮没有新增其他语言的翻译。

旧配置的 Language 覆盖被忽略，下次保存 NoSuffering 配置时移除；快捷键、Boss 百分比及房主规则保留。框架不再注册该键，不改动第三方配置文件中的无效历史字段。BaseLib 和 ModConfig 仍是可选适配，无硬依赖。发行版本、设计和存档兼容检查同步到 0.1.6，格式不变并接受 0.1.5 配对记录；本轮未进行旧配对记录的额外实机加载测试。

## 证据边界与恢复

本轮单人完整对局、联机、Computer Use 鼠标游玩均未执行，记录为未执行。0.1.5 的回滚、奖励随机数与原生双客户端证据见 [历史记录](2026-10-11-victory-rewards.md)，0.1.4 的完整对局见 [对局记录](2026-10-09-cua-playthrough.md)，不改记成本轮结果。死亡竞态仍待人工验证。

四个专用 NoSufferingLab 配置与存档均备份并恢复，树摘要一致；临时加入 Mac 副本的框架文件移除，原模组目录恢复。主存档不用于诊断。原始日志留在忽略的 artifacts，公开 JSON 去除机器路径，不包含游戏程序集、源码、用户存档或凭据。

复现入口：`python3 scripts/lab.py run --platform <macos|windows> --branch <public-beta|public> --headless --localization-probe --quit-after 0`；已安装 BaseLib 的专用副本加 `--baselib-probe`。入口只允许实际 Steam-off 隔离目录，不启动运行。旧配置迁移检查需在备份后的副本中放置旧 Language 字段。
