## LAN 适配

社区来源：<https://github.com/Caligula1022/SlayTheSpire2-LAN-Multiplayer>，commit `596bbefee8401d40e5fa7a79d8e6bdbaf43101c0`，GPLv3。源代码、适配补丁、构建输出及备份位于忽略目录，未纳入 NoSuffering 生产依赖。

- 对照 beta 实际程序集更新 API；恢复原生同步检查，移除社区同步超时后清空状态继续运行的替换。
- 恢复原生大厅序列化，保留 beta 新增字段；验证范围使用原生 4 人限制。
- 保留原生存档序列化、备份和读取，只路由 LAN 存档路径；经过 NoSuffering PairSave／ReadMulti。独立审查已核对原生方法在首次 await 前选定保存路径，以及 LAN 专用读取实例的备份、删除与损坏文件路径。
- 保留房主 ID 和 ID 0，持久化碰撞后实际分配的客机 ID。
- 损坏昵称缓存与主存档校验分离；昵称响应仅接受当前连接主机，重复响应使用 TrySetResult；初始化默认昵称移除 Steam API 调用。

Mac 独立进程检查 57 个 Harmony 目标并实际执行 PatchAll，通过；昵称缓存、来源、重复响应和断线响应的 10 项定向检查通过。该证据覆盖补丁注册与对应代码路径。两机实际续存待执行。

初次加入界面实测出现空背景：社区按钮强制读取 beta 已移除的 ControllerIcon 节点，异常打断原生 Ready，随后 OnSubmenuOpened 空引用。已删除该布局读取，扩展改在原生 Ready 完成后添加；离线模式下等待手动 LAN 地址，保留显式 fastmp 的原生探针路径。修复后加入页面与跨机器加入均通过。

独立审查还发现并修复：握手碰撞后的新 ID 在原生续档验证前永久保存，以及保留传输的回滚／重开误清空昵称。身份配置改为原生加入成功后提交；续档碰撞保留旧身份并拒绝；同一连接恢复时保留昵称。对应 20 项定向检查通过，覆盖真实包装方法的提交时序与清理条件。

首次 manifest 版本格式警告已修正；当前两端实际加载 LAN 2.0.3（test3）。Mac 构建零警告零错误，57 个 Harmony 目标与 PatchAll 通过；Windows 构建零警告零错误。
